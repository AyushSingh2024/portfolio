# Ayush Singh Parihar — Portfolio

A responsive portfolio inspired by theavnishkumar.in, personalized with Ayush's AI/ML projects, education, technical skills, and internship experience.

## Files

- `dist/index.html`: page content and structure
- `dist/style.css`: responsive styling
- `dist/script.js`: contact form email-draft interaction
- `dist/Ayush-Singh-Parihar-Resume.pdf`: downloadable resume
- `.openai/hosting.json`: existing Sites deployment configuration

## Run locally

Open `dist/index.html` in a browser, or serve the static files:

```sh
python -m http.server 4173 --directory dist
```

Visit http://localhost:4173. No package installation or build step is required. Fonts load from Google Fonts, with system-font fallbacks.

## Contact form

The form opens a `mailto:` draft in the visitor's email app. It does not send messages or store form submissions on a server.

## Customize

Edit the content and links in `dist/index.html`, appearance in `dist/style.css`, and contact email in both the HTML and JavaScript. Project graphics are concept illustrations made with HTML and CSS.
